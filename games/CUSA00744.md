**Mode comparison:** `Dump All` captures base, installed patch and *loaded* DLC; `Dump All + GP4FV` includes extra files and produces a verification-oriented GP4, **not a packaging-ready GP4**; `Dump Base Game Only` and `Dump Patch Only` target separate components; `Dump Remaster Only` targets a genuinely combined/remaster package; `Dump DLC Only` captures available DLC, including DLC not loaded during Dump All. Do not select a mode solely because a game has “remastered” in its commercial name.

**Packaging baseline (general upstream guidance, not title proof):** Preserve the original source; generate a packaging GP4; build base first with CyB1K/orbis-pub-gen; for a separately packaged patch, choose a patch GP4 and explicitly select the matching built base PKG under **Settings → Patch → Application Package**; validate before installation. Preserve keystone and verify trophies; a `TROPCONF.SFM` access error is not proof of encryption. Never include forbidden dumper artifacts in a packaging GP4 merely because they were dumped, or falsify original SFO identity.
